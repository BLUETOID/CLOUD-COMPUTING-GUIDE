# Cloud Computing - Long Answer Questions (7 & 10 Marks)

## Theory Examination 2023-24 (Subject Code: KML051 - 10 Marks)
1. Discuss the underlying principles of Parallel Computing. How does it contribute to the performance of cloud applications?
2. Explain the virtualization of CPU in cloud computing. How does it enable multiple virtual machines to run on a single physical processor?
3. Discuss the NIST Cloud Computing Reference Architecture. What are its key components?
4. Discuss the importance of Identity and Access Management (IAM) in cloud security. How does IAM help manage user permissions and access control?
5. What is MapReduce, and how does it contribute to the processing of big data in Hadoop?
6. Explain the concept of on-demand provisioning. How does it enhance the scalability of cloud resources?
7. Explain the importance of Distributed Computing in the context of cloud systems. Also list the essential characteristics of cloud computing as defined by NIST.
8. Discuss the key virtualization structures, such as full virtualization and paravirtualization. How do they impact system performance and efficiency?
9. Explain how virtualization supports disaster recovery in cloud computing. What role does it play in ensuring business continuity?
10. Differentiate between public, private, and hybrid clouds. In what scenarios would an organization choose one over the other?
11. Explain the features and functionalities of Amazon S3 (Simple Storage Service). How does it support scalable and secure storage in the cloud?
12. Explain the role of security standards in cloud computing. What are some widely adopted security standards in the industry?
13. Discuss the methods of Resource Provisioning in cloud environments. How do on-demand and reserved instances differ in provisioning?
14. Define Hadoop and explain its role in distributed computing. How does it handle large-scale data processing?
15. Describe Virtual Box and its use in virtualization. How does it facilitate the deployment of virtual machines?
