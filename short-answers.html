Exam Paper 01 / Subject Code: KML051

Theory Examination 2023–24 (10 Questions · 2 Marks Each)

2023–24 · Q1 Unit I 2 Marks

1. Define cloud computing and provide a brief overview of its key characteristics.
View Full-Mark 2M Answer

Definition (NIST SP 800-145): Cloud computing is a model for enabling ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources (servers, storage, networks, applications) that can be rapidly provisioned and released with minimal management effort.

5 Key Characteristics (O-B-R-R-M): (1) On-demand self-service (no human intervention), (2) Broad network access (any device over internet), (3) Resource pooling (multi-tenancy), (4) Rapid elasticity (auto scale up/down), and (5) Measured service (pay-per-use metering). Example: AWS, Azure. Unit I →

Examiner Keywords: NIST SP 800-145 Shared Pool O-B-R-R-M Pay-per-use

2023–24 · Q2 Unit I 2 Marks

2. Explain how elasticity contributes to cost optimization in cloud environments.
View Full-Mark 2M Answer

Elasticity is the ability of a cloud system to automatically scale computing resources both upward and downward in real time as workload fluctuates.

  • Eliminates Over-Provisioning: Automatically terminates idle servers during off-peak hours so organizations never pay for unused capacity.
  • Prevents Under-Provisioning: Instantly adds servers during traffic surges so apps never crash or lose sales.

Example: Netflix scales AWS EC2 servers up during Friday-night releases and scales them back down at 3 AM. Unit I →

Examiner Keywords: Scale Up & Down Over-Provisioning Pay-as-you-go

2023–24 · Q3 Unit II 2 Marks

3. Explain the significance of service-oriented architecture in cloud computing.
View Full-Mark 2M Answer

Service-Oriented Architecture (SOA) designs applications as independent, loosely coupled services communicating over standard network APIs (HTTP/REST or SOAP).

  • Foundation of Cloud Models: Directly enables IaaS, PaaS, and SaaS by exposing computing capabilities as consumable services.
  • Reusability & Interoperability: A single Payment or Auth service can be reused across web and mobile apps built in different languages, and scaled independently.
Examiner Keywords: Loose Coupling Reusability Interoperability Standard APIs

2023–24 · Q4 Unit II 2 Marks

4. Describe REST (Representational State Transfer) in the context of web services.
View Full-Mark 2M Answer

REST is a lightweight architectural style for web services where every data entity is treated as a resource identified by a unique URI (e.g., /api/users/42) and manipulated using standard HTTP methods (GET, POST, PUT, DELETE).

Key Features: It is stateless (every request carries complete context), supports lightweight JSON/XML payloads, and allows HTTP caching—making it faster and more cloud-scalable than SOAP. Unit II →

Examiner Keywords: Resource URI Stateless HTTP Verbs JSON

2023–24 · Q5 Unit II 2 Marks

5. Illustrate the role of hypervisor in virtualization.
View Full-Mark 2M Answer

A Hypervisor (Virtual Machine Monitor / VMM) is the software/firmware layer sitting between physical hardware and Virtual Machines (VMs).

  • Resource Multiplexing: Abstracts physical CPU, RAM, disk, and NICs into virtual hardware so multiple isolated guest OSes share one host simultaneously.
  • Isolation & Types: Ensures a crash in one VM never affects others. Comes as Type-1 Bare-Metal (VMware ESXi, KVM) and Type-2 Hosted (VirtualBox). Unit II →
Examiner Keywords: VMM Hardware Abstraction Isolation Type-1 & Type-2

2023–24 · Q6 Unit III 2 Marks

6. Discuss the advantages of using cloud storage over traditional on-premises storage solutions.
View Full-Mark 2M Answer
  • Zero CapEx & Pay-per-GB: Eliminates upfront SAN/NAS hardware purchases, power, and cooling bills.
  • Infinite Scalability: Expands automatically from gigabytes to exabytes without buying physical hard drives.
  • High Durability & Global Access: Multi-AZ automatic replication protects against hardware failure (e.g., Amazon S3 offers 99.999999999% durability) with anywhere internet access.
Examiner Keywords: Pay-per-GB (OpEx) Multi-AZ Replication 11 Nines Durability

2023–24 · Q7 Unit I 2 Marks

7. Explain autoscaling in cloud services.
View Full-Mark 2M Answer

Autoscaling is a policy-driven cloud mechanism that continuously monitors live metrics (such as CPU > 75%, memory, or request rate) and automatically adds instances (scale-out) during traffic surges or removes instances (scale-in) when demand drops.

Benefit: Maintains fast response times and high availability while minimizing cloud costs. Example: AWS Auto Scaling Groups. Unit I →

Examiner Keywords: Metric Thresholds Scale-Out / Scale-In AWS Auto Scaling

2023–24 · Q8 Unit II 2 Marks

8. Differentiate between monolithic and microservices.
View Full-Mark 2M Answer
  • Monolithic Architecture: UI, business logic, and data access are tightly coupled in a single deployable unit sharing one database; scaling duplicates the entire app, and one bug can crash everything.
  • Microservices Architecture: Splits the app into small, independent services (e.g., Auth, Cart, Payment), each with its own database and API; supports independent deployment, granular scaling, and strong fault isolation.
Examiner Keywords: Single Deployable Unit Independent Services Fault Isolation

2023–24 · Q9 Unit V 2 Marks

9. Define OpenStack and explain its significance in cloud computing.
View Full-Mark 2M Answer

OpenStack is a modular, open-source IaaS cloud operating system that manages pools of compute (Nova), networking (Neutron), and storage (Swift/Cinder) via a web dashboard (Horizon) and REST APIs.

Significance: Enables enterprises, telecoms, and universities to build scalable private and public clouds on commodity hardware with zero vendor lock-in. Unit V →

Examiner Keywords: Open-Source IaaS Nova / Neutron / Swift No Vendor Lock-In

2023–24 · Q10 Unit V 2 Marks

10. Explain the Google App Engine.
View Full-Mark 2M Answer

Google App Engine (GAE) is Google Cloud's fully managed Platform as a Service (PaaS) for building, deploying, and auto-scaling web applications and mobile backends without managing underlying servers or OS updates.

Key Features: Supports Python, Java, Go, Node.js, and Docker; includes automatic load balancing, scale-to-zero billing, and integrated Datastore/Memcache services. Unit V →

Examiner Keywords: Managed PaaS Sandboxed Runtimes Auto-Scaling Datastore

Exam Paper 02 / Subject Code: BCAM051

Theory Examination 2024–25 (7 Questions · 2 Marks Each)

2024–25 · Q1 Unit I 2 Marks

1. Explain the key characteristics of cloud computing.
View Full-Mark 2M Answer

NIST SP 800-145 defines 5 essential characteristics of cloud computing (O-B-R-R-M):

  1. On-Demand Self-Service: Provision compute/storage automatically without provider intervention.
  2. Broad Network Access: Accessible over the internet from any device via standard protocols.
  3. Resource Pooling: Shared multi-tenant hardware dynamically allocated across consumers.
  4. Rapid Elasticity: Scales outward and inward rapidly to match fluctuating demand.
  5. Measured Service: Automatic metering of CPU, storage, and bandwidth for pay-per-use billing.
Examiner Keywords: On-Demand Broad Access Pooling Elasticity Measured Service

2024–25 · Q2 Unit III 2 Marks

2. Define Communication as a Service (CaaS) with an example of its application.
View Full-Mark 2M Answer

Communication as a Service (CaaS) is a cloud model delivering enterprise communication tools—such as VoIP calling, video conferencing, instant messaging, and virtual PBX—over the internet on a subscription basis, eliminating expensive on-premises telecom hardware.

Application Example: Twilio (used by Uber/Swiggy to send automated OTP SMS & masked driver calls) or Zoom / Microsoft Teams for remote enterprise video meetings. Unit III →

Examiner Keywords: VoIP / PBX No Telecom Hardware Twilio / Zoom

2024–25 · Q3 Unit III 2 Marks

3. Name two popular cloud-based email platforms and their key features.
View Full-Mark 2M Answer
  1. Gmail (Google Workspace): AI-driven spam/phishing filtering, instant full-text search, large cloud storage synced with Google Drive, and seamless Google Meet/Calendar integration.
  2. Microsoft Outlook (Microsoft 365): Enterprise Exchange encryption & DLP security, Focused Inbox, and deep integration with MS Teams, OneDrive, and Office web apps.
Examiner Keywords: Gmail Outlook Spam Filtering Suite Integration

2024–25 · Q4 Unit III 2 Marks

4. What are the key advantages of using cloud services for collaboration?
View Full-Mark 2M Answer
  • Real-Time Co-Authoring: Multiple remote or in-office teammates edit the same document simultaneously (e.g., Google Docs, Microsoft 365).
  • Automatic Version Control: Eliminates duplicate file conflicts by maintaining complete edit history with instant rollback.
  • Anywhere Access & Centralized Security: Role-based sharing permissions (View/Comment/Edit) without needing local office file servers.
Examiner Keywords: Real-Time Co-Authoring Version History Anywhere Access

2024–25 · Q5 Unit II 2 Marks

5. What is the difference between System Virtual Machines (VMs) and Process Virtual Machines?
View Full-Mark 2M Answer
  • System VM: Emulates a complete physical machine and runs a full guest Operating System supporting multiple applications (e.g., Ubuntu on Windows via VMware ESXi, KVM, or VirtualBox).
  • Process VM: Creates a platform-independent runtime to execute a single application process and terminates when the program exits (e.g., Java Virtual Machine — JVM, .NET CLR). Unit II →
Examiner Keywords: Full Guest OS Single Process ESXi vs JVM

2024–25 · Q6 Unit IV 2 Marks

6. What is the purpose of the Open Cloud Consortium (OCC)?
View Full-Mark 2M Answer

The Open Cloud Consortium (OCC) is a non-profit organization of universities and enterprises dedicated to developing open standards, benchmarks, and interoperability frameworks for cloud computing.

Purpose: Enables heterogeneous clouds to share massive scientific datasets (e.g., Open Science Data Cloud) seamlessly and prevents vendor lock-in. Unit IV →

Examiner Keywords: Open Standards Interoperability Open Science Data Cloud

2024–25 · Q7 Unit IV 2 Marks

7. What is the role of firewalls in securing cloud infrastructure?
View Full-Mark 2M Answer

A Cloud Firewall (e.g., AWS Security Groups, Network ACLs, or WAF) is a virtual security barrier that inspects and filters inbound and outbound cloud traffic based on IP, port, protocol, and application rules.

Role: Blocks unauthorized access and unused ports, mitigates DDoS and web attacks (SQLi/XSS via WAF), and isolates private database subnets from the public internet. Unit IV →

Examiner Keywords: Traffic Filtering Security Groups / WAF Subnet Isolation

Exam Paper 03 / Subject Code: BCAM051

Theory Examination 2025–26 (7 Questions · 2 Marks Each)

2025–26 · Q1 Unit I 2 Marks

1. Define on-demand provisioning.
View Full-Mark 2M Answer

On-Demand Provisioning is the automated, self-service allocation of cloud computing resources (VMs, storage, networks, databases) immediately when requested via a console or API—without manual provider intervention—and automatic release when idle so users pay strictly for actual consumption. Example: Launching an AWS EC2 server in 60 seconds. Unit I →

Examiner Keywords: Self-Service Automated Allocation Zero Human Interaction

2025–26 · Q2 Unit I 2 Marks

2. List any one cloud service provider.
View Full-Mark 2M Answer

Amazon Web Services (AWS) — a leading global public cloud service provider offering IaaS, PaaS, and SaaS services such as EC2 (compute), S3 (object storage), RDS (databases), and AWS Lambda (serverless). (Other valid examples: Microsoft Azure, Google Cloud Platform (GCP), IBM Cloud.)

Examiner Keywords: AWS EC2 / S3 Azure / GCP

2025–26 · Q3 Unit II 2 Marks

3. Define Service Oriented Architecture (SOA).
View Full-Mark 2M Answer

Service-Oriented Architecture (SOA) is a software architectural paradigm where applications are composed of independent, loosely coupled, reusable services that communicate over a network via standardized contracts and protocols (HTTP/REST or SOAP) following the Publish–Find–Bind model. Unit II →

Examiner Keywords: Loosely Coupled Reusable Services Publish–Find–Bind

2025–26 · Q4 Unit II 2 Marks

4. Explain the term Systems of Systems (SoS) briefly.
View Full-Mark 2M Answer

A System of Systems (SoS) is a large-scale integrated system formed by combining multiple operationally and managerially independent systems so they cooperate to deliver an emergent capability none could provide alone.

Example: A travel portal (MakeMyTrip) integrating independent airline reservation systems, hotel engines, and payment gateways. Unit II →

Examiner Keywords: Operational Independence Emergent Behavior Travel Portal Example

2025–26 · Q5 Unit III 2 Marks

5. Expand IaaS, PaaS, and SaaS.
View Full-Mark 2M Answer
  • IaaS: Infrastructure as a Service — virtualized servers, storage & networks (e.g., AWS EC2).
  • PaaS: Platform as a Service — managed app runtime & deployment platform (e.g., Google App Engine).
  • SaaS: Software as a Service — ready-to-use web software (e.g., Gmail, Salesforce).
Examiner Keywords: Infrastructure Platform Software

2025–26 · Q6 Unit IV 2 Marks

6. State two cloud security challenges.
View Full-Mark 2M Answer
  1. Data Breaches & Misconfiguration: Sensitive data stored on cloud servers can be leaked due to weak encryption, stolen credentials, or accidentally public storage buckets.
  2. Multi-Tenancy & Insider Threats: Sharing physical infrastructure among tenants creates isolation risks, while malicious or careless insiders can abuse valid credentials.
Examiner Keywords: Data Breaches Misconfiguration Multi-Tenancy Insider Threats

2025–26 · Q7 Unit V 2 Marks

7. Define OpenStack.
View Full-Mark 2M Answer

OpenStack is a free, modular, open-source IaaS cloud computing platform used to build and manage public and private clouds by controlling pools of compute (Nova), networking (Neutron), and storage (Swift/Cinder) through a unified dashboard (Horizon) and REST APIs. Unit V →

Examiner Keywords: Open-Source IaaS Private & Public Cloud Nova / Neutron / Swift
