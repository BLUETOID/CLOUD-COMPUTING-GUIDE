01 / Big Data Processing (Asked in 2023–24, 2024–25 & 2025–26!)

Apache Hadoop & HDFS Architecture

Core Design Principle

Apache Hadoop is an open-source Java framework for distributed storage and parallel processing of massive datasets across clusters of inexpensive commodity servers. Instead of moving gigabytes of data across slow networks to a compute server, Hadoop follows Data Locality ("Move Computation to Data").

4 Core Hadoop Ecosystem Modules

  1. HDFS (Hadoop Distributed File System): Fault-tolerant distributed storage splitting large files into 128 MB blocks with 3× replication.
  2. MapReduce: Distributed parallel batch processing engine based on <Key, Value> pairs.
  3. YARN (Yet Another Resource Negotiator): Cluster scheduler (ResourceManager + NodeManagers) allocating CPU/RAM containers across nodes.
  4. Hadoop Common: Shared Java utilities, I/O libraries, and OS-level abstractions.

Quick HDFS Numerical Example

Suppose you upload a 300 MB log file to HDFS (default block size = 128 MB, replication factor = 3):

  • HDFS splits it into 3 blocks: Block 1 = 128 MB, Block 2 = 128 MB, Block 3 = 44 MB.
  • Total physical cluster storage used = 300 MB × 3 = 900 MB across DataNodes.

02 / Parallel Processing Engine (Asked in 2023–24 & 2025–26)

Working of MapReduce (With Neat Diagram & Example)

MapReduce processes petabytes of data in parallel across a Hadoop cluster by dividing every job into two developer-defined functions—Map() and Reduce()—connected by Hadoop's automatic Shuffle & Sort engine.

03 / Desktop Virtualization (Asked in 2023–24 & 2025–26)

Oracle VirtualBox in Cloud Development & Testing

Oracle VM VirtualBox is a free, open-source, cross-platform Type-2 (Hosted) Hypervisor running on Windows, Linux, and macOS hosts. It allows engineers to run complete multi-VM cloud topologies locally on a laptop.

VirtualBox Networking Modes (Great Exam Detail!)

VirtualBox Virtual Networking Modes for Cloud Simulation
ModeHow It WorksCloud Testing Use Case
NATVM shares host's IP to reach the internet; hidden from external network.Quick internet access for downloading packages inside a VM.
Bridged AdapterVM gets its own LAN IP directly from the Wi-Fi/office router.Testing a web server accessible from other laptops on the LAN.
Host-OnlyPrivate network strictly between Host PC and Guest VMs (no internet).Safe isolated security/malware testing and local SSH access.
Internal NetworkConnects VMs only to each other—invisible even to the host OS.Simulating private VPC database subnets & multi-node Hadoop clusters.

Five Roles of VirtualBox in Cloud Dev & Testing

  • Zero-Cost Local Cloud Sandbox: Practice Linux administration, Docker, Kubernetes, and OpenStack locally with $0 cloud bills.
  • Snapshots & Instant Rollback: Capture VM state before applying risky patches or schema migrations; revert in 3 seconds on failure.
  • Environment Parity with Vagrant: Share a Vagrantfile so every developer boots the exact same OS/library stack used in cloud production.
  • OVF / OVA Cloud Portability: Export tested VMs as standard .ova images and import them straight into AWS EC2 or Oracle Cloud.

OpenStack Architecture & Core Components

OpenStack is a modular, open-source IaaS cloud operating system enabling enterprises, telecoms, and universities to run private and public clouds on commodity hardware without vendor lock-in.

06 / Interconnected Clouds

Cloud Federation & Four Levels of Federation

Cloud Federation interconnects two or more independent cloud providers so they share compute/storage pools, authenticate users via Single Sign-On (SAML/XMPP), and route workloads seamlessly across boundaries.

Memory Hook — P-V-E-T (Ascending Security): Permissive → Verified → Encrypted → Trusted.
