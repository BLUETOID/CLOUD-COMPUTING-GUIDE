UNIT I / 01

Introduction to Cloud Computing

NIST definition, evolution from mainframes to cloud, parallel vs distributed computing (Flynn's taxonomy, Amdahl's law, CAP theorem), 5 essential characteristics, scalability vs elasticity, on-demand provisioning, benefits and challenges.

Open Unit I → UNIT II / 02

Cloud Enabling Technologies

SOA, monolithic vs microservices, REST principles, Systems of Systems (SoS), SOAP vs REST, Publish/Subscribe messaging, virtualization basics, types & levels, hypervisors, CPU/memory/I/O/network virtualization, and disaster recovery (RPO/RTO).

Open Unit II → UNIT III / 03

Cloud Architecture, Services & Storage

Layered cloud architecture, NIST 5-actor reference architecture, public/private/hybrid clouds, IaaS/PaaS/SaaS/CaaS/Serverless, cloud CRM & collaboration tools, architectural challenges, block/file/object storage, and Amazon S3.

Open Unit III → UNIT IV / 04

Resource Management & Cloud Security

Inter-cloud resource management, Open Cloud Consortium (OCC), resource provisioning methods, global cloud exchange, cloud security challenges, SaaS security issues & protection, firewalls, insider threats, VM security, IAM, and security standards.

Open Unit IV → UNIT V / 05

Cloud Technologies & Advancements

Hadoop architecture, HDFS & MapReduce with diagrams, VirtualBox in cloud dev/testing, Google App Engine (GAE) & programming environment, OpenStack architecture, cloud federation levels, plus AWS, VMware, and Nimbus.
